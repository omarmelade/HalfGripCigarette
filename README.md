# Cigarette

A [HalfGripTools](https://github.com/4l3x4nd3r0/HalfGripTools) mod for Half Grip 0.419.

A cigarette lies on top of the dash and a cigarette lighter sits right of the steering wheel. You work them with the cockpit hand, like the shifter:

1. Grab the cigarette (hold the left button).
2. Hold its tip (the left end) on the lighter until it glows.
3. Right click with the cigarette in the hand to take a drag: a few seconds of slow motion, a narrower view and darker screen edges.

A cigarette has 3 drags. Let it go and it falls, then it is back on the dash (a new one if it was finished).

## Install

In the HalfGripMods installer, press **+ ADD** and paste:

```
https://github.com/omarmelade/HalfGripCigarette/tree/main/Cigarette
```

By hand: copy the `Cigarette` folder into `<game>\BepInEx\HalfGripMods\`.

## Settings

`BepInEx\config\halfgrip.cigarette.cfg`: effect length and strength, drags per cigarette, zoom, vignette, and where the lighter and the cigarette sit (`Place`).

The mod reads and writes nothing but its own config file. No network, no save access.
